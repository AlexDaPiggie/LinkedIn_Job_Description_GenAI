How it works

You answer a few questions. The AI writes a draft. Plain rules check it. You edit it and take it.

1 AI call per draft - 0 extra AI calls for the quality check

What you can count on

You stay in control

Every edit can be undone. Nothing changes unless you click.

No invented numbers

The AI never writes pay. Your range is added exactly as you typed it.

Free to generate

No account needed. Only the typed "Refine" box uses a credit.

The five steps

  1. 01 You

    You describe the job

    Answer a few questions, or upload an old posting and let it fill them in.

    Example Acme, Data Analyst, $80,000 - $100,000

  2. 02 AI

    The AI writes a draft

    It fills labelled sections from your answers: summary, duties, requirements.

    Example "Acme is hiring a Data Analyst to turn sales data into clear reports..."

  3. 03 Code

    We check it is complete

    A missing or broken section is caught before you see it. We retry once, then show a clear error.

    Example A draft with no "Requirements" section is retried.

  4. 04 Rules

    We check the wording

    Simple word lists, not another AI, flag hype words, age-coded and gender-coded wording, and missing pay.

    Example "Rockstar" and "ninja" are flagged as hype. "Digital native" is flagged as age-coded.

  5. 05 You

    You edit and take it

    One-click tweaks, rewrite one section, undo anytime. Then copy for LinkedIn or download Word.

    Example Click "More casual" and the tone changes in one click.

What it does not do

  • It does not let the AI write your pay numbers.
  • It does not use extra AI for the quality check, so the same draft gets the same result every time.
  • It does not charge for generating, quality checks or quick edits.

The same steps, in technical terms

  1. 01 Intake

    Collect the facts

    Guided questions, or upload an old job description and let it fill them in. Pay range is optional and typed by you.

    in role notes or a file
    out structured answers

  2. 02 Generate

    Ask the AI for structured output

    Fixed instructions come first and your data last, wrapped as data rather than commands. The model returns JSON, not free text.

    in answers + instructions
    out JSON draft

  3. 03 Validate

    Check the structure

    The JSON is checked against a schema. If it is cut off or malformed, it is retried once, then reported as an error.

    in JSON draft
    out valid draft or retry

  4. 04 Check

    Run the free quality rules

    Gender-coded and age-coded wording, filler words, missing pay, long bullet lists, reading level, and requirements that are not in your answers.

    in valid draft
    out score + findings

  5. 05 Deliver

    Show it, then edit it

    LinkedIn-ready text with copy and Word export. One-click edits, section rewrites and undo are free.

    in checked draft
    out post, Word file

Design choices

  • Pay numbers

    Never written by the AI

    Your range is formatted by code and attached after generation, so the model cannot invent or change it.

  • Quality rules

    Plain rules, no extra AI cost

    Word lists from published research on gendered and age-coded job ads. A screening aid, not proof of bias.

  • Verify marks

    Added requirements are flagged

    Requirements that share no words with your answers are marked, so you can check or remove them.

  • Uploads

    Treated as untrusted text

    File text is cleaned, capped and wrapped in delimiters, and extracted fields are filtered to known names and types.

Money and safety

  • Credit ledger

    One step, never twice

    One database function checks and subtracts credits in a single step. Each charge has a unique key, so a repeated request never charges twice.

  • Payments

    Prices set on the server

    Stripe Checkout with a fixed pack list. Webhooks are verified and credit once per checkout session, and failed attempts are retried by Stripe.

  • Free endpoint

    Bot check and limits

    Cloudflare Turnstile, a per-IP daily limit that reads the address only from trusted proxies, and a global daily cap as a kill switch.

  • Signup

    One free grant per mailbox

    Email must be confirmed first. Gmail dots and plus tags are collapsed, and throwaway email domains are blocked.

Stack

Vanilla JavaScript front end, FastAPI back end, Supabase for sign-in and data, Stripe Checkout for payments, OpenRouter for model access, hosted on Hugging Face Spaces. The quality rules live in src/quality and run without the rest of the app. See how the model was chosen.
