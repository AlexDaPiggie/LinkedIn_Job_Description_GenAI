Standard DevOps Engineer Job Description

About [Company Name]

[Company Name] is a high-growth technology company on a mission to build products that empower modern teams. We value autonomy, rapid execution, and an inclusive culture where great ideas win.

About the Role

We are seeking an experienced DevOps / Cloud Platform Engineer to automate deployments, ensure 99.99% system availability, and manage infrastructure as code.

Key Responsibilities

  • Design, build, and maintain cloud infrastructure across AWS or GCP using Terraform.
  • Manage and optimize production Kubernetes clusters (EKS / GKE) for high availability.
  • Develop and enhance automated CI/CD deployment pipelines using GitHub Actions or GitLab CI.
  • Implement robust monitoring, logging, and alerting systems using Prometheus, Grafana, and Datadog.
  • Collaborate with development teams to improve application reliability, security, and build times.
  • Participate in an on-call rotation with blameless post-mortem culture.

Required Qualifications

  • 3+ years of dedicated DevOps, SRE, or Cloud Infrastructure experience.
  • Deep expertise with Linux system administration, networking, and shell scripting (Bash/Python).
  • Strong hands-on experience with Docker and Kubernetes in production environments.
  • Proficiency in Infrastructure as Code (IaC) using Terraform.
  • Experience configuring CI/CD pipelines and managing automated release lifecycles.

Preferred Qualifications (Nice-to-Haves)

  • AWS Certified Solutions Architect or CKA (Certified Kubernetes Administrator).
  • Experience with security compliance (SOC 2, ISO 27001, HIPAA).
  • Familiarity with serverless architectures and database clustering.

Benefits & Perks

  • Top-tier compensation and equity.
  • Full health, dental, and vision benefits.
  • 100% remote work policy with home office stipend.
  • Generous on-call stipend and flexible time off.
  • Annual education and tech conference budget.

Equal Opportunity Employer

[Company Name] is an equal opportunity employer. We celebrate diversity and are committed to creating an inclusive environment for all employees regardless of race, religion, color, gender, sexual orientation, or background.
