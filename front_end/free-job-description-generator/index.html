What every generated job description includes

Each draft follows the same structure: about the company, about the role, key responsibilities, required qualifications, nice-to-haves, benefits, pay (if you add it) and an equal opportunity statement. Sections are checked before you see them. If one is missing or broken, the tool retries once and shows a clear error instead of a half-written post.

Any requirement that does not match your answers is marked "verify", so the AI cannot quietly add a degree or a tool you never asked for. You stay in control of what gets posted.

Frequently asked questions

Is the job description generator really free?

Yes. You get the full job description, not a preview, with no account. The wording check, one-click edits, section rewrites, undo, copy to LinkedIn and Word export are also free.

What costs money?

Only custom refine requests, where you type your own change such as "add a remote work section". Each one uses 1 credit. A free account includes 20 credits. After that, credits are $5 for 20, with no subscription. A failed refine returns the credit.

Do I need to sign up or add a card?

No. You can write, check, copy and export a job description without an account or a card. An account is only needed to use refine credits.

Is there a limit on free job descriptions?

There is a daily usage limit and a bot check to stop abuse. Normal use, such as writing several job descriptions in a day, fits well inside it.

How do you keep it free?

Each draft uses one AI call to a model picked in our evaluation for good quality at low cost. The quality check uses plain rules, not a second AI, so it costs almost nothing. Optional refine credits cover the rest.

Can I edit the job description after it is generated?

Yes. Use free one-click tweaks, rewrite a single section or undo. For changes in your own words, use a refine credit. You can also edit freely after you copy it or download the Word file.
